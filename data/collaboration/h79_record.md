# RID直显与AOA多目标态势改动报告

本轮按用户给出的“检测采集—特征识别—协议与身份解析—定位与轨迹”链路修改现有Web地面站。主目录为 `F:\2026fpga\rid_receiver\ground_station`，态势入口为 `http://127.0.0.1:18770/#/monitor`，刷新旧页请按 Ctrl+F5。

## 整体链路与本轮范围

```text
检测采集：保留实际接收频率、信道与历史抓包来源
  ↓
特征识别：按接收证据显示 OFDM / DSSS / PHY待确认、802.11及已观测HT协议
  ↓
协议与身份解析：RID消息、ID、Location；或有证据的疑似图传信源
  ├─ 有RID身份和新鲜有效位置 → 直接绿色无人机 + RID广播轨迹
  ├─ 缺少有效RID位置，但有识别依据 → 同源IQ → A/B AOA → 黄色无人机 + AOA轨迹
  └─ 普通/未知Wi-Fi、依据不足 → 保留信源观测，不虚构无人机位置
```

用户提到的历史5 GHz及更高频率记录继续保留，没有做2.4 GHz过滤或删除原始频率。本轮核对源码后确认：当前采集服务仍是各站固定信道接收，不能由历史频率推断正在同时扫描2.4 GHz、5 GHz及更高频段。本次在页面明确区分“实时固定信道”和“历史/导入频率”，没有增加尚未验证的扫频或改动板端RF。实现真正多频多信道监测还需相应接收链、板端调谐/轮扫与双站IQ同步方案，并经实机验证。

## 页面与处理链修改

### 1. RID直接上图

- RID桥接与地图继续独立于AOA。取得有效广播位置即可显示绿色无人机，位置变化累计为轨迹，不等待双站角度或相位标定。
- 后端处理链新增明确的定位分流。有新鲜有效RID位置的信源不再进入自动或手动AOA队列；处理链显示“RID位置直显”和“查看地图”。
- 同一身份的连续广播保持同一条轨迹；同MAC同频点有有效RID位置时，不再叠加第二个AOA无人机。
- 保留Location自己的时间，不能通过新Basic ID续活旧位置。后续只收到身份而没有位置时，可显示最后有效位置并明确标为历史；具备同源AOA结果时可回退AOA。
- 修正前端接入的一个兼容问题：合法数据未携带 `observationId` 时，首次观测也应摄入；采用时间和位置字段去重，不再被空值比较跳过。

### 2. 无有效RID位置的候选进入AOA

- 无RID的Wi-Fi只有满足既有图传/结构证据时才作为疑似无人机调度，不能仅因“没有ID”判定为黑飞。界面使用“疑似无人机／归属待核验”。
- AOA交汇位置改为黄色无人机SVG，图例同样改为黄色无人机；轨迹使用黄色虚线。A/B站点和两站中点继续显示。
- 交汇的前后多解仍分别标“候选／未消歧”，未校准或临时参考仍保留原质量边界，没有因换图标变为通过精度验收。
- 只解析到DSSS身份时可用RID位置直显；无位置的DSSS信源仍明确提示当前PHY暂不支持既有OFDM LTF测向，不能伪造AOA。

### 3. 多目标持续显示

- 增加按目标保存的DOA最近观测缓存。调度从目标一转到目标二时，地图可以同时保留各自仍有效的位置和独立轨迹，不再仅显示当前调度目标。
- 不同目标、MAC/频率、会话、参考和几何不串轨迹。会话/几何/参考变化使相关旧缓存失效；超过新鲜度的交点不再作为当前位置显示。
- RID与AOA历史点均有上限，失联间隔断开连线；不同前后分支不混为一条航迹。DOA目标缓存上限64个，沿用每条轨迹120点等已有边界。

### 4. 右侧全部目标详情

- 右侧改为纵向滚动的全部目标卡片，可同时查看多个RID无人机与多个AOA候选。
- 每卡展示该目标的定位方式、身份状态、MAC、SSID（有则显示）、频率/频段、已有PHY/协议、观测时间、位置与轨迹点数；RID卡另有广播高度、速度、航向等可用字段。
- 同一目标的身份与位置关联，不借用当前另一信源的数据填补空值。
- 左侧选择只高亮对应卡片，不过滤其他目标；定时刷新保留右侧滚动位置。
- 左侧抽屉包含AOA候选，可点击查看并定位地图；原“目标/电脑”悬停、固定和关闭方式保持。

## 用户查看方式

1. 打开 `http://127.0.0.1:18770/#/monitor`，按Ctrl+F5刷新。
2. 实机无数据时，地图保留A/B站；有RID有效位置就直接出现绿色无人机及轨迹。
3. 有识别依据但没有有效RID位置的目标，待两站取得有效同源交汇后出现黄色无人机及轨迹。
4. 右侧上下滚动查看全部目标。可在信源检测页查看每个信源的PHY/协议、身份和定位分流。
