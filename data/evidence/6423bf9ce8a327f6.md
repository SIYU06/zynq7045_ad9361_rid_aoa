# 独立 RID 接收站

本目录可以单独复制、运行，不依赖 FPGA、Vivado 或现有工程。代码与日志可以一直保存在电脑硬盘，Ubuntu U 盘只用于启动环境。

## 2. Ubuntu 上准备真实接收

必须直接启动的 Ubuntu，WSL 的虚拟网卡不能替代内置 AX201 的监听接口。先在 Windows 完整关机，避免休眠、快速启动导致 NTFS 分区不可安全写入；挂载 F 盘后，在文件管理器找到本目录并打开终端。Linux 路径一般类似 `/media/ubuntu/卷标/2026fpga/rid_receiver`，请使用实际路径。

```bash
sudo apt update
sudo apt install python3-scapy iw
iw dev
iw list
```

在 `iw list` 的 Supported interface modes 中确认有 `monitor`。AX201 是否能接收目标帧仍需实际测试。下面的 `wlp0s20f3` 仅为例子，请替换成 `iw dev` 显示的无线接口名。以下操作会使该无线接口暂时不能正常上网。

```bash
sudo nmcli device set wlp0s20f3 managed no
sudo ip link set wlp0s20f3 down
sudo iw dev wlp0s20f3 set type monitor
sudo ip link set wlp0s20f3 up
sudo iw dev wlp0s20f3 set channel 6
sudo python3 receiver.py --interface wlp0s20f3 --log ./logs/live.jsonl
```

用普通浏览器打开 http://127.0.0.1:8765 。接收程序不会自动修改网卡，也不会发送无线帧。日志路径相对于当前目录，请保持在硬盘上的项目目录运行；不指定 `--log` 时仅在内存中保留目标状态和最近 200 包。指定日志时追加保存每个成功解析的 RID 包，不自动轮转，请留意长时间运行的文件大小。

**当前只监听一个固定信道。**频道 6 是测试起点，并非所有设备都使用它；可按目标实际发射信道手动切换，例如 `sudo iw dev wlp0s20f3 set channel 149`，前提是当地法规和网卡允许。跳频会漏掉其他信道上的广播，因此此版本不承诺接收“所有 RID”。

停止程序后恢复正常上网：

```bash
sudo ip link set wlp0s20f3 down
sudo iw dev wlp0s20f3 set type managed
sudo ip link set wlp0s20f3 up
sudo nmcli device set wlp0s20f3 managed yes
```

## 3. PCAP / PCAPNG 回放

安装 scapy 后，Windows 或 Ubuntu 均可回放包含原始 802.11 帧的抓包文件。普通以太网抓包无法还原 RID 管理帧。

```bash
python3 receiver.py --pcap ./capture.pcapng
```

回放尽快处理所有包；页面时间表示导入时间，不是原始抓包时间。回放完成后服务继续运行供查看和导出。

## 支持范围及数据含义

- Wi-Fi Beacon：Vendor IE 221，OUI `FA:0B:BC`，类型 `0D`。
- Wi-Fi NAN：OpenDroneID service ID `mac_a2d0e30818`，固定 Service Descriptor `0x10` 布局。其他带可选字段的 NAN 布局暂不支持。
- 25 字节单消息及最多 9 条消息的 Message Pack；协议版本 0、1、2。未知单消息版本/类型保留原始十六进制，不推测字段。
- Basic ID、Location、Authentication、Self ID、System、Operator ID；认证消息仅展示页数据，不进行签名验证或认证数据重组。
- 不含蓝牙 RID、厂商私有 DroneID 或所有国家标准的兼容承诺。本项目不是标准合规认证工具。
- 经纬度单位为度；速度 m/s；几何高度基于 WGS84 椭球，相对高度另行标明起飞点或地面。未知值显示 `—`。
- 按源 MAC 聚合，MAC 变化可能产生新目标；同一 MAC 的历史消息可能已陈旧，请查看消息更新时间。页面显示的是广播声明，不证明身份真实。
- 默认只监听 `127.0.0.1` 的网页端口，不开放局域网访问；无需修改 Windows 防火墙。
- 内存最多保留 1000 个发射源、200 条最近包；导出为当前内存快照。完整接收历史需启动时指定 JSONL 日志。

## 排查

“接收失败”：查看页面/终端错误，确认接口名、monitor 模式、root 权限和 scapy 安装情况。
无线帧增长但 RID 为 0：可能没有 RID 发射源、信道不匹配、发射源采用蓝牙/其他协议。
无线帧始终为 0：检查网卡驱动、固件、监听模式和射频开关，不能据此判断周围没有无人机。
端口冲突：加 `--port 8766`，然后打开对应地址。
